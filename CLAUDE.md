# CLAUDE.md

Die Arbeitsregeln dieses Repositorys stehen in **[`AGENTS.md`](AGENTS.md)** – eine Datei für alle Agenten,
damit die Regeln nicht in zwei Fassungen auseinanderlaufen. **Bitte dort zuerst lesen.**

Das Wichtigste in Kürze:

- **Vier Dokumente, vier Rollen**: [`Plan.md`](Plan.md) ist das Gedächtnis, [`Preparation.md`](Preparation.md)
  die Arbeitsliste, [`Befunde.md`](Befunde.md) das Messprotokoll (dorthin zeigen alle Verweise „G1"–„G21"),
  [`README.md`](README.md) die Außendarstellung.
- **Der Pitch ist der Taktgeber**, nicht das gerade Messbare.
- **Zu ChurchTools-Verhalten vorab in der [Academy](https://churchtools.academy/de/) recherchieren** – die API
  zeigt Zustände, die Dokumentation zeigt Regeln.
- **Ein `404` der API beweist nichts**, und **eine leere Liste ist kein Beweis für „es gibt nichts"**.
- **Schreibende Zugriffe auf die Testinstanz vorher besprechen.** Lesen ist frei.
- **Keine Zugangsdaten und keine Instanz-URL ins Repo**; `fixtures/` ist nicht versioniert.
- **Dokumentation deutsch, Code englisch, Commit-Betreff deutsch ohne Umlaute.**
